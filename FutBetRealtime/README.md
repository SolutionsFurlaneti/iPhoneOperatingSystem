# FutBetRealtime · IOS

Versão 1.0.3.

[Instalar FutBetRealtime no iPhone](https://www.furlaneti.com.br/futbet/)

1. Abra o link no Safari.
2. Toque em Compartilhar.
3. Escolha Adicionar à Tela de Início.
4. Se aparecer Abrir como App, mantenha ativado e toque em Adicionar.

O ícone abre o jogo com login, partidas, moedas fictícias e assinatura. Precisa de internet. As atualizações chegam pelo próprio site.

O ZIP desta pasta é a cópia da versão web publicada, para distribuição e auditoria. **Não é IPA e não deve ser instalado como um arquivo no iPhone.**

Apenas o pacote atual fica nesta pasta. O histórico do Git preserva versões anteriores.
