# AutoCareManager · IOS

Versão 1.0.50.

[Instalar o AutoCare Manager no iPhone](https://www.furlaneti.com.br/autocare/)

1. Abra o AutoCare Manager no Safari.
2. Toque em Compartilhar e escolha Adicionar à Tela de Início.
3. Confirme o nome e toque em Adicionar.

O ícone abre o sistema de gestão de estacionamento em modo de app. É necessária conexão com a internet; os dados e pagamentos continuam protegidos pela sessão do sistema. As atualizações chegam pelo próprio site.

O ZIP desta pasta é uma cópia da versão web para distribuição e auditoria. **Não é um IPA**: a instalação no iPhone é feita pelo Safari.

Apenas o pacote atual fica nesta pasta. O histórico do Git preserva versões anteriores.
