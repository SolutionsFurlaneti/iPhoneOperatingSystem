# NextTimeSlot · IOS

Versão 1.0.71.

[Instalar NextTimeSlot no iPhone ou iPad](https://nexttimeslot.online)

1. Abra o NextTimeSlot no Safari.
2. Toque em Compartilhar → Adicionar à Tela de Início.
3. Confirme o nome e toque em Adicionar.

A agenda abre em modo de app e exige conexão com a internet. As atualizações chegam pelo site.

O ZIP contém uma cópia da versão web para distribuição e auditoria. **Não é um IPA nem um instalador iOS**. A instalação é feita pelo Safari.

A pasta contém o pacote atual. O histórico do Git preserva as versões anteriores.
